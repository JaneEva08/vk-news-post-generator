# Генератор постов для ВКонтакте

Локальный сайт на Flask: вставляете ссылку на новость про нейросети (или её текст), выбираете тон — и нейросеть пишет готовый пост.

## Запуск

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Скопируйте `.env.example` в `.env` и заполните:
   ```
   API_KEY=ваш ключ
   API_BASE_URL=адрес Proxy API (из документации)
   MODEL=название модели (из документации)
   ```
3. Запустите:
   ```
   python app.py
   ```
4. Откройте http://127.0.0.1:5000

## Картинки

Кнопка «Сгенерировать картинку» рисует иллюстрацию по тексту поста (без надписей). Модель задаётся в `.env`: `IMAGE_MODEL=gpt-image-2`. Для истории картинка вертикальная. Вместо сгенерированной можно загрузить свою.

## Публикация во ВКонтакте

В `.env` добавьте:
```
VK_TOKEN=ключ доступа сообщества (с правом на стену)
VK_GROUP_ID=число — id сообщества, без минуса
VK_API_VERSION=5.199
```
У ключа должны быть права: стена, фотографии, истории (для картинок к постам и историй).
Ключ создаётся в сообществе: «Управление → Настройки → Работа с API → Ключи доступа». После формирования поста нажмите «Опубликовать во ВКонтакте» — перед отправкой сайт спросит подтверждение. Чтобы выложить пост позже, включите «Отложить публикацию» и выберите дату и время — ВКонтакте сам опубликует пост в этот момент (он будет лежать в «Отложенных» записях сообщества). После правки `.env` перезапустите сайт.

## Ключ пользователя для картинок

ВКонтакте не даёт загружать фото на стену ключом сообщества (ошибка 27), поэтому для постов с картинкой нужен ещё и ключ **пользователя** — аккаунта, который является администратором сообщества. Тексты без картинки по-прежнему публикуются ключом сообщества. Если картинка выбрана, а ключа нет, сайт ничего не отправит и подскажет, что делать. Картинку можно также скачать кнопкой «Скачать» под превью и прикрепить в ВК вручную.

> Важно: при подготовке этого раздела официальные страницы документации VK ID не удалось открыть автоматически. Названия кнопок и точные сроки жизни ключа могли измениться — сверяйтесь с актуальной документацией на https://id.vk.com/about/business/go/docs и https://dev.vk.com.

Как получить ключ:

1. Войдите во ВКонтакте под аккаунтом администратора сообщества.
2. Откройте кабинет VK ID для бизнеса (https://id.vk.com/about/business/go) и создайте приложение (тип — веб). Запишите его `client_id`.
3. В настройках приложения укажите адрес возврата (redirect URI), например `http://127.0.0.1:5000`.
4. Пройдите авторизацию по инструкции VK ID («Авторизация пользователя» → получение `access_token`), запросив права (scope): **photos**, **wall**, **stories**. Больше ничего не просите — чем меньше прав, тем безопаснее.
5. Скопируйте полученный `access_token` в `.env`:
   ```
   VK_USER_TOKEN=ваш ключ
   ```
6. Перезапустите сайт.

Про `offline`: это право делает ключ «долгоживущим» — иначе ключ живёт недолго (в новой схеме VK ID обычно около часа, а дальше его надо обновлять специальным refresh-ключом), и вам придётся заново получать его. Берите `offline` только если он есть в вашей версии документации и без него ключ слишком быстро истекает. Если ключ перестал работать (ошибка 5), получите новый.

**Безопасность.** Этот ключ даёт доступ к вашему личному аккаунту. Храните его только в `.env` (файл не попадает в git), не вставляйте в код, чат и скриншоты и никому не показывайте. Если ключ утёк — отзовите доступ в настройках безопасности ВКонтакте и получите новый.

Истории: если `VK_USER_TOKEN` задан, истории публикуются им, иначе — ключом сообщества, как раньше.

## Как менять стиль поста

Правила (структура, длина, хештеги, эмодзи) лежат в файле `voice.md`. Меняйте его как обычный текст — перезапуск не нужен.

## Что внутри

- `app.py` — сервер, загрузка статьи, запрос к нейросети
- `templates/index.html`, `static/` — страница, стили, скрипт
- `voice.md` — правила поста
- `.env` — секреты (не попадает в git)

## Если ссылка не открывается

Некоторые сайты закрыты от парсинга — переключитесь на вкладку «Текстом» и вставьте текст новости.
