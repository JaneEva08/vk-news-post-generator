# Генератор постов для ВКонтакте

Локальный сайт на Flask: вставляете ссылку на новость про нейросети (или её текст), выбираете тон — и нейросеть пишет готовый пост.

## Запуск

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Скопируйте `.env.example` в `.env` и заполните:
   ```
   API_KEY=ваш ключ
   API_BASE_URL=адрес Proxy API (из документации)
   MODEL=название модели (из документации)
   ```
3. Запустите:
   ```
   python app.py
   ```
4. Откройте http://127.0.0.1:5000

## Публикация во ВКонтакте

В `.env` добавьте:
```
VK_TOKEN=ключ доступа сообщества (с правом на стену)
VK_GROUP_ID=число — id сообщества, без минуса
VK_API_VERSION=5.199
```
У ключа должно быть право на стену.
Ключ создаётся в сообществе: «Управление → Настройки → Работа с API → Ключи доступа». После формирования поста нажмите «Опубликовать во ВКонтакте» — перед отправкой сайт спросит подтверждение. Чтобы выложить пост позже, включите «Отложить публикацию» и выберите дату и время — ВКонтакте сам опубликует пост в этот момент (он будет лежать в «Отложенных» записях сообщества). После правки `.env` перезапустите сайт.

## Как менять стиль поста

Правила (структура, длина, хештеги, эмодзи) лежат в файле `voice.md`. Меняйте его как обычный текст — перезапуск не нужен.

## Что внутри

- `app.py` — сервер, загрузка статьи, запрос к нейросети
- `templates/index.html`, `static/` — страница, стили, скрипт
- `voice.md` — правила поста
- `.env` — секреты (не попадает в git)

## Если ссылка не открывается

Некоторые сайты закрыты от парсинга — переключитесь на вкладку «Текстом» и вставьте текст новости.
